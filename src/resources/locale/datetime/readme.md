
For the martian calendars, there are three naming schemes provided.

### Darian
The Darian calendar names months using the names of the zodiac constellations, alternating between the English and Sanskrit names. 
In my reading, I haven't seen a three letter abbreviation scheme for months in the Darian calendar. Taking inspiration from the Utopian calendar, for the English constellation names the IAU abbreviations are used.

Resources:
- https://ops-alaska.com/time/gangale_mst/darian.htm#months
- https://en.wikipedia.org/wiki/Darian_calendar

### Utopian
The Utopian calendar uses the names of animal constellations that aren't in the zodiac. 
The IAU three-letter abbreviation for each constellation is used as the month abbreviation.

Resources:
- https://marscalendar.com/sols-of-the-week
